# 路线图

[README](../README.zh.md) · [English](roadmap.md) · [当前版本对比](comparison.zh.md)

更新于 **2026-09-10**，以 **dsh-filesnap 0.2.2** 为基准。以下是计划改进，不是已发布功能或发布日期承诺。优先级用于安排实现，完成需有实际功能及验证结果。

## 计划事项

| 优先级 | 改进 | 完成标准 |
|---|---|---|
| P1 | **快照清理命令与设置面板** | 将引擎回收、会话删除接入插件；执行前预览范围及删除内容。保护仍被保留快照和 redo 状态引用的数据。 |
| P1 | **保留策略与可选自动清理** | 可配置时间、数量、存储策略与受保护会话；显示受影响的恢复点并报告失败。自动清理由用户主动开启。 |
| P1 | **空间占用与去重检查** | 分开展示实际正文占用、元数据和共享对象引用，说明统计范围；接入引擎 `doctor`，提供存储健康检查入口。 |
| P1 | **恢复预览与 diff 界面** | 执行前显示目标轮次、将写入或删除的文件、排除路径，以及对共用工作区的影响。 |
| P2 | **仅回退对话模式** | 显式选择文件不变的模式，定义该模式的 fork 与 redo 行为，并与对话/文件同步恢复区分。 |
| P2 | **逐文件恢复选择器** | 从已捕获恢复点选择文件并预览变更；明确提示局部恢复后文件可能不再对应完整对话状态。 |
| P2 | **更顺畅的分支与 redo 导航** | 清楚展示原会话、子会话和继续目标，改善手动命令后的跳转；保留原对话并说明工作区共用。 |
| P1 调研 | **减少会话读取对插件事件注册的依赖** | 调研宿主支持的事件注册或兼容迁移方案；验证卸载/重装和支持的宿主升级后，再宣称当前限制已解决。 |

引擎已有 `gc`、`doctor` 和会话删除能力，插件命令、设置、策略控制和预览仍需实现。路线图条目不代表存在可直接执行的新命令。

## 当前版本边界

当前插件尚未提供独立的仅回退对话模式、清理界面、逐文件恢复选择器或 diff 界面。回退会创建与原会话共用工作区的子会话。

**卸载不会删除对话记录或工作区文件。** 含插件记录的会话目前需要重装插件后才能在 DSH 中重新打开。上面的事件注册调研不代表这一限制已经修复。

实现后在 release notes 中记录对应插件、引擎和宿主版本。存储清理需验证保留的恢复数据不受损；交互改动需验证对话/文件状态以及对应的 redo 行为。
